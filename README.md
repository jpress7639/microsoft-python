# Microsoft Python Development Certificate 

I completed the Microsoft Python Development Professional Certificate, a comprehensive six-course program covering the full arc of professional Python development. 

## Course 1-2: Python Programming Fundamentals and Data Analysis/Visualization

It started with core programming fundamentals — language syntax, data structures like lists and dictionaries, and foundational algorithms — before moving into data analysis and visualization, where I worked hands-on with pandas to clean and transform real datasets and used Matplotlib to build clear, effective visualizations.

## Course 3-4: Automation/Scripting and Web Development

From there, the program shifted into automation and scripting: writing Python scripts to automate file operations, extract data using regular expressions, and scrape web data with tools like BeautifulSoup. The web development portion went deep on Flask, covering routing, templating, and database integration with SQL, alongside web security fundamentals like preventing SQL injection and XSS vulnerabilities.

## Course 5: Advanced Development Techniques with Python 

The program's advanced track covered more sophisticated engineering patterns — data structures like graphs, trees, and linked lists, along with decorators, generators, and advanced object-oriented design — paired with hands-on experience using generative AI tools throughout the development lifecycle and deploying applications to Azure, including Flask apps and serverless Azure Functions.

## Course 6: Project Development and Deployment

It closed with a capstone focused on real-world project delivery: applying project management and Agile principles to Python development, working with DevOps tooling like Docker and Kubernetes, and building a functional chatbot from scratch — rounding out the technical work with a genuine, practical understanding of how Python projects actually move from idea to production.
